# 工作規則

- 不得閱讀或複製老師範例網站的原始碼。
- 不得修改 VERIFY.md；驗收項目由我決定。
- 必要時可以調整 PLANS.md，並在完成報告中說明調整內容。
- 不得製作 BRIEF.md 沒有要求的功能。
- 不得違反 BRIEF.md 中的技術限制。
- 一次只執行一個步驟，完成後先回報。
- 每個步驟都使用測試驅動開發。
- 先撰寫測試，再執行一次並確認測試失敗，之後才撰寫功能。
- 不得為了讓測試通過而修改測試。
- 先提交測試，再撰寫功能。
- 所有測試通過後，才能提交功能修改。
- 只有測試通過後，才能在 PLANS.md 勾選完成。
- 遇到需求不清楚的地方，先詢問我。
- 每個步驟完成後，回報哪些測試先失敗、後來通過，以及修改了哪些檔案。
