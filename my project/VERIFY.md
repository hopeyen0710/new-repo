# 驗收項目

## STEP 0：天空島

- [ ] 遊戲能以靜態網站方式開啟。
- [ ] 畫面中看得到 3D 浮空島。
- [ ] 玩家可以行走與跳躍。
- [ ] 世界尺寸不超過 32 × 32 × 32 個方塊。
- [ ] 遊戲不使用伺服器、帳號或多人連線。

## 第一批：破壞 → 掉落 → 撿起 → 放置

### STEP 1：破壞方塊

- [ ] 持續按住泥土方塊上的滑鼠左鍵，裂痕會逐漸出現，且方塊在 1 秒內消失。
- [ ] 只按一下滑鼠左鍵，方塊仍然存在。
- [ ] 破壞到一半放開滑鼠左鍵，裂痕會消失。
- [ ] 破壞石頭所需時間比破壞泥土長，約為 2 秒。

### STEP 2：方塊掉落

- [ ] 方塊消失時，會掉出一個相同種類的小方塊並緩慢旋轉。
- [ ] 小方塊會落在地面並停留在地面上。
- [ ] 小方塊不得懸浮或穿過地面。

### STEP 3：撿起方塊

- [ ] 玩家走到小方塊旁邊時，小方塊會飛向玩家。
- [ ] 對應物品欄的數量增加 1。
- [ ] 玩家距離小方塊 3 個方塊時，不會撿起它。

### STEP 4：放置方塊

- [ ] 選擇數量大於 0 的物品欄格子並在地面按滑鼠右鍵，會放置一個方塊。
- [ ] 放置後，物品欄數量減少 1。
- [ ] 物品數量為 0 時，按滑鼠右鍵不會放置方塊。
- [ ] 完成「破壞一個方塊 → 撿起 → 放置」後，物品數量回到原本數量。

## 第二批：下雨功能

### STEP 5：切換下雨

- [ ] 天氣晴朗時按 R，下雨開始，畫面看得到落下的雨滴。
- [ ] 下雨時再按 R，下雨停止。
- [ ] 下雨時，玩家仍能行走、跳躍、破壞方塊與放置方塊。
- [ ] 下雨不得新增或移除方塊，也不得改變物品欄數量。
